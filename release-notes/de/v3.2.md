Dragon Quest IX Modern v3.2: Installation und Update funktionieren wieder auf PCs, auf denen der Build abbrach.

**Behoben seit v3.1**
- **„python: command not found“, „No module named 'yaml'“, „unable to lock database“**: Ein mittendrin abgebrochener Build (Fenster geschlossen, PC ausgeschaltet) hinterließ eine Sperre, die danach jede Installation der Build-Werkzeuge blockierte. Die Installation entfernt diese Sperre jetzt und prüft die Werkzeuge vor dem Kompilieren; fehlt noch etwas, sagt sie, was zu tun ist.
- **Spiel ohne SDL3.dll**: Das vollständige Update der Werkzeuge konnte SDL2 durch ein anderes Paket ersetzen; SDL2 bleibt jetzt unangetastet.
- **„BUILD FAILED“ bei offenem Spiel**: SDL2.dll wird nur noch kopiert, wenn sie sich geändert hat.

**Schon installiert?** Das Spiel bietet das Update beim Start an (oder Hilfe > Nach Updates suchen): Spielstände und Einstellungen bleiben erhalten. **Hängt es an einem dieser Fehler?** Die Installation mit dieser Version erneut starten.

**Mit Freunden spielen**: Alle brauchen dieselbe Version, also aktualisiert alle auf v3.2.
