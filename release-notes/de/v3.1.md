Dragon Quest IX Modern v3.1: Die Installation funktioniert wieder auf PCs, auf denen sie mit einem Python-Fehler abbrach.

**Behoben seit v3**
- **Die Installation funktioniert wieder**: Über RecompLauncher oder `Install Dragon Quest IX.bat` konnte die Installation bei „Recompiling the game“ mit `ImportError: DLL load failed while importing binascii` abbrechen. Die Build-Werkzeuge wurden nur halb aktualisiert (ein neueres Python mit seinen alten Bibliotheken). Die Installation aktualisiert die Werkzeuge jetzt zuerst vollständig und installiert dann, was sie braucht. Ohne Internet geht sie wie bisher mit den bereits installierten Werkzeugen weiter.

**Schon installiert?** Das Spiel bietet das Update beim Start an (oder Hilfe > Nach Updates suchen): Spielstände und Einstellungen bleiben erhalten. **Hängt es beim binascii-Fehler?** Die Installation mit dieser Version erneut starten.

**Mit Freunden spielen**: Alle brauchen dieselbe Version, also aktualisiert alle auf v3.1.
