Dragon Quest IX Modern v3.2 : l'installation et la mise à jour fonctionnent de nouveau sur les PC où le build s'arrêtait.

**Corrigé depuis la v3.1**
- **« python: command not found », « No module named 'yaml' », « unable to lock database »** : un build arrêté en plein milieu (fenêtre fermée, PC éteint) laissait un verrou qui bloquait ensuite toute installation des outils. L'installation retire maintenant ce verrou et vérifie les outils avant de compiler ; s'il manque encore quelque chose, elle dit quoi faire.
- **Le jeu privé de SDL3.dll** : la mise à jour complète des outils pouvait remplacer SDL2 par un autre paquet ; SDL2 n'est plus touché.
- **« BUILD FAILED » avec le jeu ouvert** : SDL2.dll n'est recopié que s'il a changé.

**Déjà installé ?** Le jeu propose la mise à jour au démarrage (ou Aide > Rechercher des mises à jour) : vos sauvegardes et réglages sont conservés. **Bloqué sur une de ces erreurs ?** Relancez l'installation depuis cette version.

**Jouer entre amis** : tout le monde doit avoir la même version, passez donc tous à la v3.2.
