Dragon Quest IX Modern v3.2: installing and updating work again on PCs where the build stopped.

**Fixed since v3.1**
- **"python: command not found", "No module named 'yaml'", "unable to lock database"**: a build that was stopped half way (its window closed, the PC turned off) left a lock that blocked every install of the build tools after it. The install now removes that stale lock and checks the tools before building; if something is still missing, it says what to do.
- **The game left without SDL3.dll**: the full update of the build tools could swap SDL2 for another package; SDL2 is now left alone.
- **"BUILD FAILED" with the game open**: SDL2.dll is copied only when it changed.

**Already installed?** The game offers the update when it starts (or Help > Check for updates): your saves and settings are kept. **Stuck on one of these errors?** Run the install again from this version.

**Playing with friends**: everyone needs the same version, so all of you update to v3.2.
