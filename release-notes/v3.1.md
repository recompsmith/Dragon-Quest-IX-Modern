Dragon Quest IX Modern v3.1: installing works again on PCs where it stopped on a Python error.

**Fixed since v3**
- **Installing works again**: from RecompLauncher or `Install Dragon Quest IX.bat`, the install could stop at "Recompiling the game" with `ImportError: DLL load failed while importing binascii`. The build tools only half updated (a newer Python with its old libraries). The install now updates the build tools fully first, then installs what it needs. Offline, it goes on with the tools already installed, as before.

**How to install**: download *Source code (zip)* below, unzip it and double-click `Install Dragon Quest IX.bat`, then choose your own ROM (USA or European). Or install it from RecompLauncher. On Linux or the Steam Deck, see `docs/LINUX-STEAMDECK.md`. **Already installed?** The game offers the update when it starts (or Help > Check for updates): your saves and settings are kept. **Stuck on the binascii error?** Run the install again from this version.

**Not included, on purpose**: no ROM, no game executable and no data from any game. Everything is built on your PC from the ROMs you own. The HD pack only holds remade pictures and movies, downloaded by the game.

**Playing with friends**: everyone needs the same version, so all of you update to v3.1.
