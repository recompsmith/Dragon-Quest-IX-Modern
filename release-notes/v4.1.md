Dragon Quest IX Modern v4.1: type your character's name with the keyboard again.

**Fixed since v4**
- **Character creation**: on the name screen (new game, and "Create a companion" at Patty's), the PC keyboard did nothing on a new install. Typing the name with the keyboard is now on by default, also for existing settings; it can still be turned off in Modern > Type the character's name with the keyboard.

**Already installed?** Open the launcher (or the game): it updates itself, your saves and settings are kept.

**Playing with friends**: everyone needs the same version, so all of you update to v4.1.
